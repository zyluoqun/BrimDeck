BrimDeck 行情绿色版（Windows x64）

解压整个目录后双击 BrimDeck.exe，不需要安装程序或另装 .NET。
portable.flag 使设置、缓存写入本目录的 data 文件夹。移动时保留整个目录。

行情直接连接服务端，与 AutoOrder.exe 无关。
将专用的 market-feed.json 放在 BrimDeck.exe 旁；请勿将其中的只读授权上传到公开仓库。
GitHub 构建产物只有不含授权的 market-feed.example.json。

展开面板包含 AI 用量、音乐、系统监控、市场行情四个模块。原来的音乐控制、任务列表、告警和窗口规则保留。
在页签或面板空白区域使用滚轮切换模块；行情列表内部的滚轮用于上下浏览列表。
市场行情页提供热门、涨幅榜、跌幅榜的完整列表，点击币种通过 OpenMarket 官方接口切换已打开网页中的图表。
行情窗口按榜单内容自动调整宽度，更新时间自动换行，减少两侧空白；高度可在展开面板设置中调整。
收起摘要和展开页分别设置，关闭一个摘要不会关闭其他模块或市场行情页。

设置 → 收起外观：
刘海、胶囊都有独立的“币种行情”开关，和配额、音乐、监控、时钟共同显示，可拖动排序。
行情摘要只显示币种和24H涨跌幅。悬停行情区域暂停滚动，不弹提示和展开面板；其余区域沿用原来的悬停展开设置。
指标条保留原高度，在右侧用短标记提示行情，悬停进入完整榜单；音乐播放进度保留。
“当前生效”说明显示窗口规则是否将所选外观切换为了指标条。开启监控后，请确认实际生效的外观对应的监控开关。
宽度不足时可启用原有“自适应宽度”设置，原来的手动尺寸和全屏规则仍可使用。
手动加宽刘海或胶囊时，新增空间用于显示更多币种，其他已启用模块继续保留。
设置 → 展开面板可设置四个模块的显示、默认页和尺寸；行情页的宽度自动适配内容。

升级时保留原来的 market-feed.json。全新解压后，也可在市场行情页点击“导入配置”选择已有配置文件。
GitHub ZIP 不包含个人只读授权；请沿用自己已有的配置。
右键行情区域或双击托盘图标可以打开设置。
如果关闭系统动画，可用鼠标滚轮查看横条中的其他币种。
报价过期显示“—”；网络异常会显示不可用状态，不以旧报价冒充当前数据。

网页图表联动：
在 OpenMarket 的智能体管理页创建“图表控制”令牌，只需读取与控制图表权限。
设置 → 展开面板 → 市场行情 → 网页图表联动：填写图表地址（或布局 ID）和令牌，保存。
令牌通过 Windows 当前用户加密，保存在 data/openmarket-chart-token.dat；布局 ID 保存在 data/openmarket-chart.json。
请勿公开或随 GitHub ZIP 分发这两个个人配置文件。更换 Windows 用户或电脑、令牌到期时，需要重新配置令牌。
首次使用：在 Chrome 中打开 chrome://extensions，开启开发者模式，点击“加载已解压的扩展程序”，选择本程序目录中的 chrome-extension 文件夹（BrimDeck Chart Window）。只需在日常使用并已登录 OpenMarket 的 Chrome 用户中加载一次。
扩展 ID 为 klighcgglcfkihjcbdcapjijfhebokff；本机连接自动注册到当前 Windows 用户。移动程序目录后，启动新目录下的 BrimDeck 即会更新本机连接；如扩展目录也变动，需重新加载该文件夹。
点击币种时，优先复用 2 号显示器上的 OpenMarket 图表标签，在网站内切回配置的四屏布局，再执行切币。同一屏有多个图表标签时优先使用目标布局或之前记住的标签。
2 号屏没有图表、其他屏有时，只移动所选 OpenMarket 标签：优先移入 2 号屏已有的普通 Chrome 窗口，否则将该标签拆成独立窗口放到 2 号屏。原窗口内的其他网页留在原处。所有窗口都没有可复用图表时，在 2 号屏的 Chrome 中新建图表标签；没有该屏窗口时新建窗口，Chrome 未启动时先启动。登录、授权管理等页面不会被替换。
目标标签会被激活，其所在窗口在 Windows 显示设置中的 2 号显示器进入与 F11 相同的浏览器全屏状态；已在该屏全屏时保持原状态。找不到 2 号显示器或网页需要登录时，提示失败，不执行切币。胶囊点击的布局须为上方一屏、下方三屏，且关闭币种同步与周期同步。
扩展更新到 1.3.0 后，需要在 chrome://extensions 对 BrimDeck Chart Window 点击一次“重新加载”。窗口识别不依赖币种标题，可区分同币种的不同图表窗口；临时识别标记在激活后清除，异常时也会自动到期清除。
滚动币种带有 1、2、3 等榜单序号，循环滚动的副本沿用相同序号。
部分中文交易对在行情目录中有效，但 OpenMarket 的 chart_symbol 接口当前仍有 ASCII 字符校验限制。遇到该拒绝时保留轮换位置，并明确提示在网页手动选择；不将中文交易对改写为其他市场。
点击收起行情或展开榜单的币种，共用下方左 → 中 → 右 → 左的顺序；每次切换目标屏至 4h，上方屏不变。
设置 → 展开外观 → 市场行情 → 网页图表联动中，可固定下方窗口 1（左）、2（中）、3（右），最多同时固定两个。固定窗口保留当前币种和周期，不参与轮换；只剩一个未固定窗口时，后续点击都切换该窗口。取消固定后恢复原顺序。设置自动保存，对下一次切换生效，重启后保留。
优先复用已有四屏标签页，不刷新整个布局；目标屏保留原来的指标和样式。重启程序或重新保存联动配置后，从下方首个未固定窗口开始。
从点击到执行完成期间，暂停行情条滚动，在对应币种后显示加载环；成功、失败或取消后清除加载状态，恢复原有滚动规则（鼠标悬停仍暂停）。连续点击按顺序执行，全部完成前保持暂停。
页面未打开、布局不匹配、授权过期或网络异常时，会提示操作未完成；失败不推进轮换顺序。
接口只确认保存时，程序会继续向浏览器标签页读取实际币种和周期；网页尚未确认执行，不会推进轮换顺序。
网页闲置后连接或状态同步暂未就绪时，程序会先有限等待恢复；切币后网页确认延迟时，也会继续核验实际币种和周期，不重复发送切币请求。两个等待阶段分别最多 10 秒、5 次检查。
Chrome 建议在 chrome://settings/performance 的“始终保持这些网站处于活动状态”中添加 openmarket.xyz，减少后台标签页休眠。
自动等待后仍未恢复时，请切回已经打开的四屏标签页，必要时刷新后重试；无需重新创建令牌，也无需每次点击都刷新。
服务返回 503 等临时故障时，只读检查会有限重试，提示中会区分 HTTP 服务故障、网络连接失败和请求超时。
切换请求丢失回执时，会先检查目标屏是否已切换，避免同一次操作重复推进轮换。
data/chart-link.log 记录请求步骤、状态码和耗时，便于排查联动故障，不记录授权令牌。

本构建只生成免安装 ZIP，不通过原项目的自动更新替换程序。请从定制仓库的 GitHub Actions 下载新版，升级时保留 data 文件夹和 market-feed.json。

收盘倒计时：
设置 → 收起外观 → 刘海或胶囊 → 时间下面的“收盘倒计时”。默认同时显示 15m、1H、4H，可分别勾选，也可按外观关闭。
倒计时固定显示，与滚动行情、时钟和监控共存；展开行情页同样显示所选周期，不显示下次收盘的本地时刻。
按币安标准 UTC K 线边界计算，每秒更新；最后 1 分钟橙色、10 秒红色，可关闭变色。到点直接进入下一根 K 线。
复用现有行情服务返回的当前时间校准，不逐秒请求交易所。绿点表示已校时；橙点表示未校时、校时过期或连接失败，倒计时继续估算。
收盘声音和桌面通知默认关闭，可在同一区域开启。提醒仅在已校时时发送，同时收盘的周期合并为一次提醒；启动、休眠恢复不补发历史提醒。
默认开启“1H / 4H 收盘打开 BTC&ETH”，可在收盘倒计时设置中关闭。仅所勾选周期在已校时状态下准时收盘时触发，15m 不打开图表；1H 和 4H 同时收盘时仅执行一次 4H。启动、休眠恢复、断网或校时失效期间不补开历史图表。
自动打开账号中名称精确为 BTC&ETH 的现有布局，并设置为左右双图：左 BTCUSDT、右 ETHUSDT，均为币安 USDT 永续；两侧同时切到本次收盘的 1h 或 4h 周期。保留原布局的指标和样式，必要时关闭币种同步。缺少该布局或存在多个同名布局时提示失败，不改动其他布局。
自动打开与胶囊点击共用上述 2 号屏标签选择、单独移动和全屏逻辑，按顺序执行；自动失败使用桌面通知，不弹出阻塞对话框。复用市场行情设置中的图表令牌，无需再次填写。
