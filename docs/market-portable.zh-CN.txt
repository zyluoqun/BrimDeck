BrimDeck 行情绿色版（Windows x64）

解压整个目录后双击 BrimDeck.exe，不需要安装程序或另装 .NET。
portable.flag 使设置、缓存写入本目录的 data 文件夹。移动时保留整个目录。

行情直接连接服务端，与 AutoOrder.exe 无关。
将专用的 market-feed.json 放在 BrimDeck.exe 旁；请勿将其中的只读授权上传到公开仓库。
GitHub 构建产物只有不含授权的 market-feed.example.json。

展开面板包含 AI 用量、音乐、系统监控、市场行情四个模块。原来的音乐控制、任务列表、告警和窗口规则保留。
在页签或面板空白区域使用滚轮切换模块；行情列表内部的滚轮用于上下浏览列表。
市场行情页提供热门、涨幅榜、跌幅榜的完整列表，点击币种打开对应图表。
收起摘要和展开页分别设置，关闭一个摘要不会关闭其他模块或市场行情页。

设置 → 收起外观：
刘海、胶囊都有独立的“币种行情”开关，和配额、音乐、监控、时钟共同显示，可拖动排序。
行情摘要只显示币种和24H涨跌幅。悬停行情区域直接进入完整榜单，其余区域沿用原来的默认页面设置。
指标条保留原高度，在右侧用短标记提示行情，悬停进入完整榜单；音乐播放进度保留。
“当前生效”说明显示窗口规则是否将所选外观切换为了指标条。开启监控后，请确认实际生效的外观对应的监控开关。
宽度不足时可点击“适配已开启内容的宽度”，原来的手动尺寸和全屏规则仍可使用。
设置 → 展开面板可设置四个模块的显示、默认页及各自尺寸。

升级时保留原来的 market-feed.json。全新解压后，也可在市场行情页点击“导入行情配置”选择已有配置文件。
GitHub ZIP 不包含个人只读授权；请沿用自己已有的配置。
右键行情区域或双击托盘图标可以打开设置。
如果关闭系统动画，可用鼠标滚轮查看横条中的其他币种。
报价过期显示“—”；网络异常会显示不可用状态，不以旧报价冒充当前数据。

本构建不生成安装包，不使用安装版的自动更新。
